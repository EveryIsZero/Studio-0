一、简介与安装

1. Overview & Install

Studio 0 是一款面向工业自动化的 Modbus 调试与上位机工具，支持 RTU / ASCII / TCP / IP 协议，提供寄存器监控、报文分析与可视化组态。

Studio 0 is a Modbus debugging & HMI tool for industrial automation, supporting RTU/ASCII/TCP/IP, with register monitoring, packet analysis and visual panel building.

二、快速上手

2. Quick Start

  1. 建连接：选协议（如 Modbus TCP）+ 连接方式，填 IP/端口，点「连接」。
  2. 加寄存器：寄存器监控中点「批量添加」，设置地址、功能码、数量。
  3. 读 / 写 / 看：点「读取」刷新；双击单元格写值；勾选「波形」看趋势。
  1. Connect: pick protocol (e.g. Modbus TCP) + link mode, enter IP/port, click Connect.
  2. Add registers: in Register Monitor click Batch Add, set address/function/quantity.
  3. Read / Write / View: click Read to refresh; double-click a cell to write; tick Waveform.
