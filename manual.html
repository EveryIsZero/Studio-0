Studio 0 — Modbus Debugging Tool · User Manual

Studio 0 是一款专业级 Modbus 协议调试与仿真工具，支持 RTU / TCP / ASCII 三协议，主从双模式，开箱即用（无需安装 Python）。

Studio 0 is a professional Modbus debugging & simulation tool supporting RTU / TCP / ASCII, master & slave modes, ready to use out of the box (no Python needed).

2. 快速上手（5 分钟）

2. Quick Start (5 minutes)

  1. 工具栏点击「新建连接」，选择协议（RTU / TCP / ASCII）并配置参数（端口、波特率、IP 等）。
  2. Click "New Connection" on the toolbar, pick a protocol (RTU / TCP / ASCII) and set parameters (port, baud, IP...).
  3. 在数据配置区「添加数据点」：填写从站地址、功能码、起始地址、数量、数据类型。
  4. In data config, "Add Data Point": slave address, function code, start address, quantity, data type.
  5. 点击「连接」→ 选中数据点 →「启动采集」，实时数值随即显示。
  6. Click "Connect" → select points → "Start Acquisition"; live values appear.
  7. 双击数值列写入新值并确认下发。
  8. Double-click a value to write a new value and confirm.

4. 数据类型与功能码

4. Data Types & Function Codes

支持 INT16/UINT16/INT32/UINT32/FLOAT32/FLOAT64/HEX/STRING/BYTE ARRAY/BIT。换算公式：实际值 = 原始值 × 系数 + 偏移。字节序支持 ABCD/DCBA/BADC/CDAB。

功能码：01 读线圈 / 02 读离散输入 / 03 读保持寄存器 / 04 读输入寄存器 / 05 写单线圈 / 06 写单寄存器 / 0F 写多线圈 / 10 写多寄存器。

Function codes: 01 Read Coils / 02 Read Discrete Inputs / 03 Read Holding Registers / 04 Read Input Registers / 05 Write Single Coil / 06 Write Single Register / 0F Write Multiple Coils / 10 Write Multiple Registers.

5. 核心功能

5. Core Features

  • 从站仿真：模拟 Modbus 从设备，配置数据映射表供主站联调。
  • Slave Simulation: simulate a slave with a mapping table for master testing.
  • 多设备管理：同时连接多台设备，各自独立配置。
  • Multi-Device: connect many devices, each independently configured.
  • 通讯日志：记录全部报文（十六进制 + 解析），可导出。
  • Comm Log: records all frames (hex + decoded), exportable.
  • 报警系统：上下限/偏差/变化率报警，声音/弹窗/日志通知。
  • Alarms: high/low/deviation/rate alarms via sound/popup/log.
  • 图形组态：仪表盘、曲线、状态灯、指令按钮等控件。
  • Graphical HMI: gauges, trends, status lamps, command buttons.
  • 脚本自动化：定时/条件触发的数据采集与写入。
  • Script Automation: scheduled/conditional acquisition and writing.

6. 常见问题

6. FAQ

无法启动？ 确保 Studio 0.exe 与 _internal/ 同目录；将程序移到纯英文路径；安装 VC++ 运行库；杀软加白名单。

Won't start? Keep exe with _internal/; move to an English path; install VC++ runtime; whitelist in antivirus.

数据全 0 / 乱码？ 检查从站地址、功能码、字节序、地址偏移。

All zeros / garbage? Check slave address, function code, byte order, address offset.

配置备份？ 备份整个 cfg/ 文件夹即可。

Backup config? Back up the whole cfg/ folder.
