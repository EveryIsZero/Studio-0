5 分钟快速上手

  1. 从 Releases 下载压缩包并解压。
  2. 运行 Studio 0.exe，在左侧连接面板选择 COM 端口或填入 TCP 地址。
  3. 点击「连接」，设备上线后切换至「输入/输出绑定 — 位操作」等标签页。
  4. 用滑块、按钮直接读写保持寄存器 / 线圈，实时查看报文。
  5. （进阶）打开脚本编辑器，用 Python 编写定时采集或自动报警逻辑。
